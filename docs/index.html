Task Manager Pro

A robust, library-based C++ CLI application for task management.

Features

  • Library Architecture: Core logic decoupled from CLI.
  • JSON Config: Flexible settings via config.json.
  • Cross-Platform: Works on Windows and Linux.
  • CI/CD: Automated testing and documentation.

Quick Start

mkdir build
cmake -S . -B build
cmake --build build
./build/task_app add "Hello World"
./build/task_app list

API Documentation can be generated using cmake --build build --target docs.
